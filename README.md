# Ephphatha

## sensor_reader
(esp-idf)
A script to output flex sensor continuously onto serial monitor.

## test_pipeline
(arduino)
A script to convert .tflite model into a usable Model.h
A script to run inference on this Model.h using a set of test values. Model output will be tested for accuracy and inference time.

## data_collection
(esp-idf)
A script that allows user to input label and then capture flex sensor values for that given label, and then inputs labels and values into a csv

## Mark733
To be flashed into ESP32 S3 for working demo
